Update the “Schedule your showing now” button behavior so it immediately notifies Follow Up Boss when clicked, then shows the user a popup to choose Call or Text.

Current desired behavior:
When someone clicks “Schedule your showing now,” two things should happen:

1. A popup/modal/bottom sheet opens and lets the user choose:
   - Call
   - Text

2. Immediately when they click “Schedule your showing now,” before they choose Call or Text, send a Follow Up Boss notification with:
   - the property address they are currently viewing
   - the user’s name, if available
   - the user’s email, if available
   - the user’s phone, if available
   - the service tab they were on
   - the current page URL
   - timestamp

Reason:
Even if the user clicks “Schedule your showing now” but does not actually call or text, FUB should still receive the request so the agent can follow up later.

Scope:
Apply this to every place the “Schedule your showing now” CTA exists:
- Purchase with Loan, only when result = Likely Qualifies
- Purchase with Cash, always under the home photos
- any shared Schedule Showing component

PART 1 — Main button behavior

Button text remains:

“Schedule your showing now”

When clicked:
1. Immediately send a FUB notification/event:
   - event type: `showing_request_started`
   - property address
   - user name/email/phone if available
   - service tab
   - current page URL
   - normalized_property_key if available
   - qualification status if Purchase with Loan
   - estimated price if available
2. Then open the popup/modal/bottom sheet with Call/Text options.

Important:
The FUB notification should happen on the initial Schedule button click, not only after the user clicks Call or Text.

If FUB notification fails:
- still open the Call/Text popup
- do not block the user
- log the error
