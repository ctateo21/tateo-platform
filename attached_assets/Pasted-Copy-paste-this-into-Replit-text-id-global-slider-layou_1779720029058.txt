Standardize slider formatting across the entire website/app.

Current issue:
Sliders throughout the app are not consistently formatted. Some sliders stretch too far, values are not positioned cleanly, and the label/value relationship is not clear.

Requested global slider layout:
For every slider on the website/app, format it like this:

- The slider should sit directly under the row/label/value it references.
- The slider should take about 3/4 of the row width.
- The remaining 1/4 of the row should be used for the value/summary text that explains what the slider is controlling.
- The value should appear at the end/right side of the slider row.
- The slider should not run all the way to the edge of the card/row.

Visual concept:

Top row:
Label / description / current selected value

Slider row:
[ slider takes 75% width ] [ value/summary takes 25% width ]

Examples:

Seller Concessions (% of Purchase Price)
[---------slider---------]   2.00% / $10,000

Discount Points (% of Loan Amount)
[---------slider---------]   1.0% / $3,000

Down Payment
[---------slider---------]   20.00% / $100,000

Apply this to all sliders across the entire app, including:
- Purchase with Loan
- Purchase with Cash
- Refinance
- Insurance
- Sell Your Home
- Dashboard detail views
- Page 3 Purchase Details
- Page 4 See My Estimate
- Real Estate cards
- Mortgage cards
- Seller concessions sliders
- Down payment sliders
- Discount points sliders
- Seller closing costs sliders
- Any other slider component used anywhere in the app

Preferred implementation:
Create or update a reusable slider layout component instead of manually fixing every slider.

Suggested reusable component:
`LabeledSliderRow` or `SliderField`

It should support:
- label
- helper text
- slider
- formatted value display
- optional min/max/step
- optional mode toggle if the slider has Percentage/Dollar Amount
- mobile wrapping

Suggested layout:

Desktop:
- label/helper row full width
- slider/value row uses CSS grid:
  - slider column = 3fr
  - value column = 1fr
- slider in first column
- value text in second column
- align value text cleanly
- keep enough spacing between slider and value

Mobile:
- stack cleanly:
  - label
  - slider full width
  - value underneath or right-aligned below
- do not make the mobile slider cramped

Important formatting requirements:
1. Slider must be directly under the item it references.
2. Slider should be compressed to around 75% width on desktop.
3. Value/summary text should live in the remaining 25%.
4. Slider should stop before the end of the row/card.
5. Value should be visually tied to the slider.
6. Do not let the slider overlap with the value.
7. Do not break mode toggles like Percentage / Dollar Amount.
8. Do not break calculations.
9. Do not change the actual slider min/max/step values unless already required by the field.
10. This is a layout/styling cleanup, not a calculation change.

Preserve existing behavior:

- cash to close
