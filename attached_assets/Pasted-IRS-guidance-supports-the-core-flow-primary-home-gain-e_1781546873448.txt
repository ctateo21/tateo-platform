Create a shared helper.

- checklistItems

Use these constants:
- SINGLE_EXCLUSION = 250000
- MARRIED_EXCLUSION = 500000
- ESTIMATED_CAPITAL_GAINS_TAX_RATE = 0.20

Version 1 calculation:
```

adjustedCostBasis = priorPurchasePrice + capitalImprovements

grossEstimatedGain = max(0, estimatedSalePrice - adjustedCostBasis)

```

Primary residence Yes:
```

exclusionAmount = filingStatus === "married" ? 500000 : 250000
excludedGain = min(grossEstimatedGain, exclusionAmount)
taxableGain = max(0, grossEstimatedGain - exclusionAmount)
estimatedTaxesDue = taxableGain * 0.20

```

Primary residence No:
If assume1031Exchange = true:
```

exclusionAmount = 0
excludedGain = 0
taxableGain = 0
estimatedTaxesDue = 0

```

If assume1031Exchange = false:
```

exclusionAmount = 0
excludedGain = 0
taxableGain = grossEstimatedGain
estimatedTaxesDue = taxableGain * 0.20

```

Unknown primary residence answer:
```

estimatedTaxesDue = 0
status = "needs_primary_residence_answer"

```

Missing prior purchase price:
```

estimatedTaxesDue = 0
status = "needs_prior_purchase_price"

```

No gain:
If estimatedSalePrice <= adjustedCostBasis:
```

grossEstimatedGain = 0
taxableGain = 0
estimatedTaxesDue = 0

```

Important:

Keep this helper isolated so future tax calculation upgrades are easy.
