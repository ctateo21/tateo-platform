The below-720 FHA rule is now working, but it created a new loan recommendation priority bug.

Current issue:
If the user says they are:
- buying a primary residence, and
- they are a veteran / VA eligible

the app still keeps the loan type as FHA when credit score is below 720.

That is wrong.

Expected behavior:
VA eligibility should override the below-720 FHA rule when the property is a primary residence.

Loan recommendation priority should be:

1. VA loan
If the user is VA eligible / veteran AND the property is a primary residence:
- loan type should automatically become VA
- this should override the FHA below-720 rule
- down payment should follow VA logic, usually 0% down unless the app has another VA rule
- VA funding fee logic should apply
- FHA DPA should not show

2. FHA loan
If the user is not VA eligible, or the property is not a primary residence, and credit score is below 720:
- loan type should automatically become FHA
- standard FHA down payment = 3.5%
- FHA DPA should be available as an option

3. Existing normal logic
If user is not VA eligible and credit score is 720 or above:
- use the existing normal recommendation logic

Hard rule:
VA primary residence eligibility should beat FHA credit score logic.

Examples:
- Veteran = Yes, occupancy = Primary, credit score = 680 → VA
- Veteran = Yes, occupancy = Primary, credit score = 740 → VA
- Veteran = Yes, occupancy = Investment, credit score = 680 → FHA, because VA primary occupancy requirement is not met
- Veteran = No, occupancy = Primary, credit score = 680 → FHA
- Veteran = No, occupancy = Primary, credit score = 740 → existing logic

Please update the loan recommendation logic to apply priority order, not isolated rules.

Suggested centralized helper:
Create or update one function like:

`getRecommendedLoanType({ creditScore, isVeteran, isVaEligible, occupancyType })`

Logic:

```js
if ((isVeteran || isVaEligible) && occupancyType === "primary") {
  return "va";
}

if (Number(creditScore) < 720) {
  return "fha";
}

return existingRecommendationLogic(...);
