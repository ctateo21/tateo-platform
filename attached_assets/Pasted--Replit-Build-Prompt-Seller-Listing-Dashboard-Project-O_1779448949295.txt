# Replit Build Prompt — Seller Listing Dashboard

## Project Overview

Build a **real estate seller dashboard** web app for a real estate agent's platform. Sellers log in and see a live, personalized dashboard for each of their active listings. The dashboard surfaces everything a seller needs to understand how their property is performing — market comps, days on market, online platform engagement estimates, price recommendations, and next steps — all updated weekly by the agent.

---

## Tech Stack

- **Frontend:** React (with Tailwind CSS for styling)
- **Backend:** Node.js + Express
- **Database:** Supabase (PostgreSQL) for listing data, agent notes, and weekly recap entries
- **Auth:** Supabase Auth (email/password for sellers; separate agent admin login)
- **Charting:** Recharts
- **Hosting:** Deploy on Replit with a custom domain hook

---

## User Roles

### 1. Agent (Admin)
- Logs in via `/admin`
- Can create, edit, and update listings
- Inputs weekly recap data manually (views estimates, comps, recommendations, price drop suggestions)
- Can publish/unpublish recaps visible to sellers

### 2. Seller (Client)
- Logs in via `/dashboard`
- Sees only their own listings (linked via `seller_id`)
- Read-only view of all dashboard data
- Can see historical weekly recaps in a timeline

comp_2_price          integer

comp_3_address        text

## Pages & Features

### Seller Dashboard — `/dashboard`

**Header**
- Seller's name + brokerage logo
- "Last updated: [date]" badge
- Active listing count

**Listing Selector**
- If seller has multiple listings, show a tab or dropdown to switch between them

**Per-Listing Dashboard View**

Each listing shows the following sections:

#### 1. Listing Overview Card
- Address, MLS#, list price, bed/bath/sqft
- Status badge (Active / Pending / Sold)
- Days on market vs. market average (shown as a number + color-coded indicator: green <28 days, amber 29–60, red 60+)

#### 2. Price Analysis Panel
- Current list price
- Agent's recommended price range
- Agent's projected sale range
- A simple horizontal range bar showing: [projected low] ←——→ [projected high] with current list price marked
- Price drop recommendation card (amber highlight if recommended)

#### 3. Market Comps Table
- Show up to 3 comps: address, price, DOM, status (active/pending/sold)
- Color-code sold comps in green, active in blue, pending in amber
- Market context stats: inventory months, median price, avg sale-to-list %

#### 4. Online Platform Engagement Section
This is the key differentiator section. Show all three platforms side by side.

**For each platform (Zillow, Realtor.com, Redfin):**
- Estimated current views (weekly or daily depending on platform)
- Estimated saves/hearts
- A bar comparing this listing's engagement to a freshly listed comp (use the agent-entered estimate as % of baseline)
- Heat index (for Zillow only): saves ÷ views shown as a %
- Color-code: green ≥5%, amber 2–5%, red <2%

**Below the platform cards:**
Show a plain-language explanation written by the agent (pulled from `engagement_summary` field) explaining what the numbers mean and what action is recommended.

**Benchmark reference strip** (always visible):
- 250+ daily views → pending in ~1 week
- 5+ daily saves → under contract in a week
- <1 save/day → 30+ days on market expected
- <25 views/day → critical — pricing or presentation issue

#### 5. Next Steps Panel
- Render `next_steps[]` as a checklist-style list
- Each item has a checkbox (decorative — not interactive for sellers, but agent can mark as complete in admin)
- Color each item: uncomplete = amber bullet, complete = green checkmark

#### 6. Weekly Recap History Timeline
- Show past recaps in a collapsible accordion list, sorted newest first
- Each entry shows: date, DOM at time, list price at time, key agent note
- Lets the seller see their listing's full history over time

---

### Agent Admin — `/admin`

**Listings Manager**
- Table of all active listings with seller name, address, DOM, last recap date
- "Add Listing" button → form to create new listing and link to seller account
- Click any listing → opens the Recap Editor

**Recap Editor**
- Form with all fields from `weekly_recaps` table
- Rich text area for narrative fields (market_summary, engagement_summary, next_steps)
- "Save Draft" and "Publish to Seller" buttons
- Preview mode shows exactly what the seller will see before publishing

**Seller Management**
- Create seller accounts (name, email, linked listings)
- Send invite email via Supabase Auth

## Design Guidelines

- Clean, professional real estate aesthetic
- Color palette: white backgrounds, dark navy text (#0F172A), accent color teal (#0D9488) for positive signals, amber (#D97706) for warnings, red (#DC2626) for critical flags
- Mobile responsive — sellers will often view on phone
- No jargon — write all UI labels in plain seller-friendly language (e.g. "Online Interest Score" not "Heat Index")
- Every metric should have a plain-English tooltip explaining what it means
