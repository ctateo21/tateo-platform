Build Discount Points into the Purchase with Loan estimate for all loan options, using the correct buydown table by loan type.

Location:
Purchase with Loan → Page 4 / See My Estimate → Real Estate card

Placement:
Add Discount Points directly under the Seller Concessions row/control on the Real Estate card.

The Real Estate card order should be:
1. Purchase Price
2. Down Payment
3. Loan Amount
4. Estimated Closing Costs
5. Seller Concessions
6. Discount Points
7. Any other real estate cost items

Purpose:
Users should be able to buy down their interest rate by selecting discount points. This should also increase closing costs based on the selected point amount.

Discount Points input:
- Default = 0.0%
- User should be able to select/type:
  - 0.0%
  - 0.5%
  - 1.0%
  - 1.5%
  - 2.0%
  - 2.5%
  - 3.0%
- Max = 3.0%
- Step = 0.5%
- Display cleanly:
  - 0.0%
  - 0.5%
  - 1.0%
  - 1.5%
  - 2.0%
  - 2.5%
  - 3.0%

Discount point cost calculation:
Discount point cost is based on the loan amount.

Formula:
discount_points_cost = loan_amount × discount_points_percent / 100

Example:
Loan amount = $300,000
Discount points = 1.0%
Discount point cost = $3,000

This amount should increase closing costs and cash to close.

Important:
- Discount points should increase buyer closing costs.
- Discount points should increase cash to close.
- Discount points should not reduce purchase price.
- Discount points should not reduce down payment.
- Discount points should not be double-counted.
- Seller concessions can offset eligible closing costs if the current app already applies seller concessions that way.

Discount point rate buydown logic:
When user selects discount points:
1. Start with the rate already calculated from all other parameters.
2. Apply the discount point rate reduction based on the loan type group.
3. Final displayed rate = base calculated rate - discount point buydown.
4. Final displayed rate should still round to 3 decimals.
5. Monthly payment should recalculate using the final bought-down rate.

Loan type table mapping:
Use the Conventional buydown table for:
- Conventional
- DSCR

Use the FHA buydown table for:
- FHA
- VA
- USDA

Do not leave VA, USDA, or DSCR with a 0.000% rate reduction.

Conventional / DSCR discount point rate reductions:
Based off the rate already calculated from the other parameters:

- 0.0% discount points = 0.000% rate reduction
- 0.5% discount points = 0.240% rate reduction
- 1.0% discount points = 0.340% rate reduction
- 1.5% discount points = 0.420% rate reduction
- 2.0% discount points = 0.500% rate reduction
- 2.5% discount points = 0.710% rate reduction
- 3.0% discount points = 0.810% rate reduction

FHA / VA / USDA discount point rate reductions:
Based off the rate already calculated from the other parameters:

- 0.0% discount points = 0.000% rate reduction
- 0.5% discount points = 0.094% rate reduction
- 1.0% discount points = 0.184% rate reduction
- 1.5% discount points = 0.264% rate reduction
- 2.0% discount points = 0.364% rate reduction
- 2.5% discount points = 0.478% rate reduction
- 3.0% discount points = 0.562% rate reduction

Loan types to support:
- Conventional

- VA
- USDA
- DSCR
- Bank Statement

- Tell me where to add a Bank Statement buydown table later.

- `rate_after_discount_points`

- `discount_points_percent = 0.0`
- `discount_points_cost = 0`

Rate calculation order:
Use this order:

1. Calculate base loan rate using existing pricing logic:
   - loan type
   - credit score
   - LTV
   - occupancy
   - AMI discount if applicable
   - existing Conventional -0.100% adjustment
   - loan term
   - all existing pricing parameters

2. Store that as:
   `rate_before_discount_points`

3. Look up the discount point rate reduction based on loan type group:
   - Conventional group: Conventional, DSCR
   - FHA group: FHA, VA, USDA
   - Bank Statement: 0.000% unless table exists

4. Apply discount point buydown:
   `rate_after_discount_points = rate_before_discount_points - discount_points_rate_reduction`

5. Round final rate to 3 decimals.

6. Use final rate for payment calculation.

Important:
- Do not apply discount point buydown more than once.
- Do not apply it before the app finishes existing pricing adjustments.
- Do not permanently mutate the base rate.
- Recalculate if loan type changes.
- Recalculate if discount points change.
- Recalculate if loan amount changes.
- Recalculate if down payment changes.
- Recalculate if purchase price changes.

Closing cost calculation:
Discount point cost should be added to total closing costs.

Example:
Base estimated closing costs = $8,000
Loan amount = $300,000
Discount points = 1.0%
Discount point cost = $3,000
Total estimated closing costs = $11,000
