Fix the For Sale → Market Analysis so it gathers real listing/market data before sending the prompt to Anthropic.

Current issue:
The Anthropic API appears to be working, but the Market Analysis is only analyzing the limited data already saved in Replit/Supabase.

The output keeps saying:
- no comps connected
- no DOM connected
- no platform engagement connected
- no pending/sold comps connected
- no local market stats connected

That means Anthropic is not being given the right real estate market data.

Important:
Anthropic does not automatically browse Zillow, Realtor.com, Redfin, Homes.com, MLS, or county/property data unless the backend first gathers that data and sends it into the Anthropic prompt.

Goal:
Before calling Anthropic, the backend should gather the best available real estate data for the property from connected/scraped/API sources, then send that data to Anthropic for analysis.

The Market Analysis should include:
- market comps
- similar active homes/condos
- similar pending homes/condos
- similar recently sold homes/condos
- how long this property has been on market vs similar homes
- whether a price drop would be beneficial
- where the property is likely to sell
- how many saves/views it has across major real estate platforms
- whether its saves/views are better or worse than similar homes/condos
- next steps to get the home or condo sold

Data sources to inspect/use:
1. Zillow/Apify property scrape
2. Zillow listing URL/ZPID data
3. Zillow photos and listing details already stored
4. Zillow views/saves if available from the scraper
5. Realtor.com listing data if available
6. Redfin listing/market data if available
7. Homes.com listing data if available
8. Stellar MLS / MLS feed if connected
9. Property cache table
10. Seller scenario data
11. County property appraiser/public record data if available
12. Any saved manual comps/market data fields
13. Any listing engagement data already stored in Supabase

Do not rely only on Anthropic to know the market.
The app must gather the data first, then Anthropic should interpret it.

Implementation requirement:
Create a backend data-gathering step before the Anthropic call.

Suggested flow:

1. User opens Dashboard → For Sale → property detail.
2. App loads seller scenario from `seller_scenarios`.
3. Backend checks if a current weekly analysis already exists.
4. If not current, backend gathers market data:
   - subject property data
   - Zillow scrape/cache data
   - active comps
   - pending comps
   - sold comps
   - DOM data
   - platform views/saves if available
   - local market stats
5. Backend sends the gathered data to Anthropic.
6. Anthropic returns structured market analysis.
7. App saves the analysis to Supabase.
8. App renders the full seller-facing recap.

Comp matching logic:
When searching for comps, prioritize:
- same property type
- same ZIP or nearby radius
- similar beds/baths
- similar sqft
- similar age/year built
- similar condo community/building if condo
- similar HOA/condo type if available
- active, pending, and sold within a reasonable recent window

For condos:
- prioritize same building/community first
- then nearby condos with similar sqft/beds/baths
- separate condo analysis from single-family analysis

For single-family homes:
- prioritize nearby homes with similar sqft, beds, baths, lot size, and age

Platform engagement:
If the scraper/API can access views/saves:
- pull Zillow views/saves
- pull Realtor.com views/saves
- pull Redfin views/saves
- pull Homes.com views/saves if available
- compare to similar active listings where possible

If exact platform views/saves are not available:
- do not make up exact numbers
- show unavailable
- explain that the app needs listing-owner/MLS/platform data connected
- still provide next steps based on available pricing/comps data

Important:
Do not fabricate:
- exact comps
- exact pending listings
- exact sold listings
- exact views/saves
- exact DOM
- exact market stats

If the app cannot access a source, mark it missing.

Anthropic prompt should say:
“You are analyzing only the structured real estate data provided below. Do not invent comps, views, saves, DOM, or platform metrics. If a data field is missing, state that it is unavailable and explain what should be connected next.”
