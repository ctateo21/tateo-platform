Add a Property Type dropdown under Purchase Price on Purchase Page 3.

Location:
Dashboard → Purchase → Page 3 Purchase Details

Placement:
Under the Purchase Price field, add a dropdown labeled:

“Property Type”

5. If the user manually changes the property type, do not overwrite it with Zillow data later.
6. Save the selected property type to the purchase scenario.
7. Persist after refresh/logout/login.
8. Page 4 / See My Estimate should use the same property type if needed.

- Single Family Residence
- Townhouse
- Condominium
- Villa
- Manufactured Home
- Multi-Family
- Duplex

- Quadplex
- Land
- Other

- buildingType

- propertySubType
- listingSubType

- SINGLE_FAMILY → Single Family Residence
