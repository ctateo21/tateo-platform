Fix the down payment control on Purchase Page 3 and Page 4 / See My Estimate so users can enter down payment as either a percentage or a dollar amount.

Locations:
1. Purchase Flow → Page 3 → Purchase Details → Down Payment
2. Purchase Flow → Page 4 → See My Estimate → Down Payment area

Current issue:
Down payment currently follows percentage-based rules, but users also need the option to enter a dollar amount.

Expected behavior:
Allow users to choose down payment mode:
- Percentage
- Dollar Amount

Keep the current default percentage rules already in place.

Examples:
- Conventional default should stay whatever the app currently defaults to.

Mode behavior:
1. If Percentage mode is selected:

2. If Dollar Amount mode is selected:
   - User enters/selects down payment dollar amount.
   - Down payment percentage is calculated from purchase price.
   - Example: $25,000 ÷ $500,000 = 5%.

Suggested fields:
- `down_payment_mode`: `"percent" | "amount"`
- `down_payment_percent`
- `down_payment_amount`

Calculation rules:
If mode is percent:
- `down_payment_amount = round(purchase_price × down_payment_percent / 100)`

If mode is amount:
- `down_payment_percent = round((down_payment_amount / purchase_price) × 100, 2)`

- Keep the selected mode as the source of truth.
- If mode is percent, recalculate the dollar amount.
- If mode is amount, recalculate the percentage.

Formatting:
- Percentage should display with two decimals:
  - 3.50%
  - 5.00%
  - 20.00%

  - $17,500
