```text id="insurance-card-occupancy-policy-autosave-fix"
Fix Insurance tab property card occupancy change so policy type updates and saves.

Current issue:
On Dashboard → Insurance, when I change a property card from Primary to Investment, the policy type does not change from HO3 to DP3.

Expected behavior:
When a user changes occupancy/property use on the Insurance property card:

Primary → Investment:
- If property type is Single Family / non-condo / non-townhouse:
  - policy type should change from HO3 to DP3
- Save occupancy_type = "investment"
- Save occupancy_type_source = "manual"
- Save policy_type = "DP3"
- Save policy_type_source = "default_rule" unless policy type was manually overridden
- Persist after refresh/logout/login

Primary or Secondary:
- If property type is Single Family / non-condo / non-townhouse:
  - policy type should be HO3

Condo/Townhouse:
- Any occupancy should be HO6

Important:
If `policy_type_source = "manual"`, do not overwrite the policy type.
But if policy type was auto/defaulted, changing occupancy should recalculate policy type.

Likely bug:
The Insurance overview/card occupancy selector is saving only `occupancy_type`, but it is not recalculating `policy_type`, or it is not saving the recalculated policy type back to `insurance_scenarios`.

Required fix:
Find the Insurance overview/card component where occupancy/property use is changed.

When occupancy changes:
1. Update local card state immediately.
2. Set:
   - occupancy_type = selected value
   - occupancy_type_source = "manual"
   - user_answer_sources.occupancy_type = "manual"
3. If policy_type_source is not "manual":
   - call `getDefaultInsurancePolicyType({ occupancyType, propertyType })`
   - update policy_type to the calculated value
   - set policy_type_source = "default_rule"
4. Save the updated row to `insurance_scenarios`.
5. Make sure the overview card reflects the new policy type immediately.
6. Make sure the detailed view reflects the same policy type.
7. Persist after refresh/logout/login.

Policy type rules:
- Primary + Single Family/non-condo → HO3
- Secondary + Single Family/non-condo → HO3
- Investment + Single Family/non-condo → DP3
- Any Condo/Townhouse/Townhome → HO6

Property type matching:
Treat as HO6:
- Condo
- Condominium
- Townhouse
- Townhome
- Town House
- Town Home
- Attached Condo
- Condo Unit

Treat as non-condo:
- Single Family Residence
- Single Family
- Detached
- Villa
- Manufactured Home
- Multi-Family
- Duplex
- Triplex
- Quadplex
- Other unless clearly condo/townhouse

Save requirements:
Save to `insurance_scenarios`:
- occupancy_type
- occupancy_type_source
- policy_type
- policy_type_source
- user_answer_sources
- updated_at

Use the existing row:
- scenario id if available
```
