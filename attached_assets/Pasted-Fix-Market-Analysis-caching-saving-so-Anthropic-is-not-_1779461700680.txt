Fix Market Analysis caching/saving so Anthropic is not called every time the user opens or refreshes the listing detail view.

Current issue:
The Market Analysis now successfully pulls useful data from Anthropic/API/web search, but the generated analysis is not being saved and reused.

What happens now:
1. I open Dashboard → For Sale → detailed listing view.
2. I click Refresh.
3. The Market Analysis loads for 15–30 seconds.
4. The full analysis appears.
5. If I leave the detail view and come back, the analysis is gone.
6. I have to click Refresh again and wait another 15–30 seconds.
7. This calls Anthropic again unnecessarily.

This is too expensive and not the intended behavior.

Expected behavior:
Once the Market Analysis is generated for a listing, it should save to Supabase and reload instantly the next time the user opens that listing.

The analysis should only regenerate automatically once per week:

Friday morning at 8:00 AM.

Do not allow normal users to manually refresh and call Anthropic repeatedly.

Required behavior:
1. When Market Analysis is generated successfully, save the complete generated analysis to Supabase.
2. When the user opens the listing detail view again, load the saved Market Analysis from Supabase.
3. Do not call Anthropic again if the saved analysis is still current.
4. The analysis should remain current until the next Friday at 8:00 AM.
5. On or after Friday 8:00 AM, generate a new analysis once, save it, and use that saved version for the rest of the week.
6. Remove or disable the user-facing Refresh button that calls Anthropic.
7. If a refresh button is needed for development/admin use, hide it behind an admin/dev-only flag.
8. Normal sellers/users should not be able to repeatedly trigger Anthropic calls.

Weekly refresh logic:
Use Friday 8:00 AM as the cutoff.

Timezone:
Use America/New_York unless the app already has a timezone setting.

Logic:
1. Calculate the current market-analysis cycle.
2. Each cycle starts Friday at 8:00 AM Eastern.
3. If the listing already has an analysis generated for the current cycle, load it from Supabase.
4. If no current-cycle analysis exists, generate a new one.
5. Save the new one to Supabase.
6. Display the saved version.
7. Do not regenerate until the next Friday 8:00 AM cycle.

Example:
- Analysis generated Friday at 8:05 AM → use it until next Friday at 7:59 AM.
- User opens page Saturday, Sunday, Monday, etc. → load saved analysis, no Anthropic call.
- User opens page next Friday after 8:00 AM → generate new weekly analysis once, save it, then reuse.
