Fix the “Who are you working with?” rep-selection persistence issue.

Current issue:
After a user creates an account and chooses the rep/person they are working with, the app still asks the same question again later.

Example:
1. I created an account.
2. I selected the rep/person I am working with.
3. I uploaded a mortgage statement.
4. I clicked “Save to my Loan Dashboard.”
5. The app asked me again who I am working with.

This should never happen after the user has already selected their rep.

Expected behavior:
Once a logged-in user selects who they are working with, that value should persist throughout the entire app.

The app should not ask again during:
- Purchase flow
- Property estimate
- Refinance flow
- Mortgage statement upload
- Save to Loan Dashboard
- Insurance flow
- Dashboard navigation
- Any later scenario/property creation

The user should only be able to change this later inside Settings/Profile.

Fix requirements:
1. Store the selected rep/person on the user profile in Supabase.
2. Use the saved profile value as the source of truth.
3. Add or confirm a persistent field such as:
   - `working_with_rep_id`
   - `selected_rep_id`
   - `preferred_rep_id`
   - or the existing equivalent field already used by the app.
4. Add or confirm a profile completion flag such as:
   - `profile_completed`
   - `onboarding_completed`
   - or the existing equivalent field already used by the app.
5. Once the saved rep value exists, skip the “Who are you working with?” screen everywhere.
6. Do not ask this question again when saving a mortgage statement to the Loan Dashboard.
7. Do not ask this question again when creating or saving a refinance record.
8. Do not ask this question again when creating or saving a purchase property estimate.
9. Do not ask this question again when creating or saving an insurance estimate.
10. Only show the question if the logged-in user truly has no saved rep value on their profile.

Important:
- Do not rely only on local state or session state.
- Do not reset the rep-selection step when the user uploads a mortgage statement.
- Do not reset the rep-selection step when the user clicks “Save to my Loan Dashboard.”
- Do not treat a new loan, refinance, insurance quote, or property estimate as new onboarding.
- Do not show this prompt just because a new scenario is being created.
- Use the authenticated user ID to load the saved profile before deciding whether to show the rep-selection screen.

Settings/Profile:
Add or confirm the user can change this later in Settings/Profile:
- Current selected rep should display there.
- User can update the selected rep.
- Updated rep should save to Supabase.
- Future flows should use the updated saved rep.

Likely causes to inspect:
- The “Who are you working with?” screen is controlled by temporary local state.
- The app checks a flow-level value instead of the user profile value.
- Mortgage statement upload/save flow triggers onboarding again.
- Save to Loan Dashboard checks for rep selection before the profile has loaded.
- The profile value is saved but not loaded before the screen is rendered.
- The saved rep field name does not match the field checked by the refinance/loan dashboard flow.
- The app is using different rep fields in different flows.
- The profile completion flag is missing or not persisted.
- Auth/profile loading is asynchronous, and the app shows the rep question before profile data finishes loading.

Implementation direction:
1. Centralize the logic into one helper, such as:
   `hasSelectedRep(userProfile)`
2. Use this helper everywhere instead of duplicating checks across flows.
3. The helper should return true if the authenticated user profile has a saved rep/person value.
4. All flows should wait until profile loading is complete before deciding to show the rep-selection question.
5. If profile is loading, show a loading state, not the rep-selection question.
6. If profile has saved rep, continue directly to the intended flow/action.
7. If profile does not have saved rep, only then show the rep-selection question.

Acceptance test:
1. Create a new account.
2. Select the rep/person the user is working with.
3. Confirm the selected rep saves to the user profile in Supabase.
4. Log out and log back in.
5. Confirm the app does not ask who the user is working with.
6. Upload a mortgage statement.
7. Click “Save to my Loan Dashboard.”
8. Confirm the app does not ask who the user is working with.
9. Start a Purchase property estimate.
10. Confirm the app does not ask who the user is working with.
11. Start a Refinance flow.
12. Confirm the app does not ask who the user is working with.
13. Start an Insurance flow.
14. Confirm the app does not ask who the user is working with.
15. Go to Settings/Profile and change the selected rep.
16. Confirm the updated rep saves and is used going forward.
